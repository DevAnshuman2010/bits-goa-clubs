# ClubHub - Pure HTML/CSS/JavaScript

A simple club management website built with vanilla web technologies.

## Files Needed

To run this website offline, you only need these files:

```
/
├── index.html          (Main HTML file)
├── style.css           (All styling)
├── script.js           (All JavaScript logic)
└── data/
    ├── clubs.json      (Club data)
    └── events.json     (Event data)
```

## How to Use

1. **Download the files above**
2. **Open `index.html` in any web browser**
3. That's it! No build tools, no npm, no dependencies required.

## Features

- **Club Guide**: Browse all available clubs
- **My Clubs**: Track clubs you follow (saved in browser localStorage)
- **Calendar**: View all upcoming events, with highlights for followed clubs
- **Fully Responsive**: Works on mobile and desktop
- **Offline Ready**: Everything runs in the browser

## Browser Compatibility

Works in all modern browsers (Chrome, Firefox, Safari, Edge)

---

**No React. No TypeScript. No Tailwind. No build process.**

Just pure HTML, CSS, and vanilla JavaScript.
